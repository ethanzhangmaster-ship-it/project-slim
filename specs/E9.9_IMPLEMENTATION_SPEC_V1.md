## 3.2 ExperimentPlan

```python
@dataclass
class ExperimentPlan:
    """Full experiment design."""
    experiment_id: str = ""
    mutation_id: str = ""          # genome_id from ExperimentCandidate
    hypothesis: str = ""           # "Changing X from A to B will improve Y by Z%"
    control: str = ""              # Original creative_id
    variant: dict = field(default_factory=dict)  # {genome_id, hook, reward, ...}
    metrics: list[str] = field(default_factory=list)  # ["CTR", "CPI", "D7_ROAS"]
    budget: float = 0.0            # Total experiment budget
    daily_budget: float = 0.0
    duration_days: int = 7
    confidence_level: float = 0.95
    statistical_power: float = 0.80
    status: str = "CREATED"        # CREATED → RUNNING → PAUSED → WINNER/FAILED/COMPLETED
```

## 3.3 ExperimentResult

```python
@dataclass
class ExperimentResult:
    """Final experiment outcome."""
    experiment_id: str = ""
    control_creative_id: str = ""
    variant_genome_id: str = ""
    spend: float = 0.0
    installs: int = 0
    ctr: float = 0.0
    cpi: float = 0.0
    roas: float = 0.0
    d7_retention: float = 0.0
    lift: float = 0.0              # (variant - control) / control
    p_value: float = 1.0
    confidence: float = 0.0
    decision: str = "INCONCLUSIVE"  # WINNER / FAILED / INCONCLUSIVE
    sample_size_required: int = 0
    sample_size_achieved: int = 0
    timestamp: str = ""
```

## Phase 2: Experiment Generation

### experiment_selector.py

**Class**: `ExperimentSelector`

**Method**: `select(candidates: list[dict], top_n: int = 20) -> list[ExperimentCandidate]`

**Logic**:
```
Experiment Priority Score = mutation_score * 0.4 + predicted_ltv_normalized * 0.3 + novelty * 0.2 + risk_inverse * 0.1
```

**Input**: Parsed top_mutations.json entries  
**Output**: `list[ExperimentCandidate]` sorted by priority  
**AC**: `len(result) >= 20`

### experiment_planner.py

**Class**: `ExperimentPlanner`

**Method**: `create_plans(candidates: list[ExperimentCandidate], baseline_performance: dict) -> list[ExperimentPlan]`

**Logic**:
For each candidate:
1. Generate hypothesis: `"Changing {mutation_type} from '{before}' to '{after}' will improve LTV by {predicted_ltv - baseline_ltv}%"`
2. Set control = parent creative_id
3. Set variant = candidate genome
4. Default metrics = ["CTR", "CPI", "D7_ROAS", "D30_LTV"]
5. Default budget = $100/day, duration = 7 days
6. Default confidence = 0.95, power = 0.80

**AC**: Every plan has hypothesis, control, variant, metrics, budget, duration

## Phase 8: Orchestrator

### experiment_engine.py

**Class**: `ExperimentEngine`

**Pipeline**:
```python
def run() -> dict[str, Any]:
    """Execute full E9.9 pipeline."""
    # Step 1: Load mutation candidates from E9.8 output
    candidates = self._load_mutations()
    
    # Step 2: Select top experiments
    selected = self._selector.select(candidates, top_n=20)
    
    # Step 3: Load baseline performance
    baseline = self._load_baseline()
    
    # Step 4: Create experiment plans
    plans = self._planner.create_plans(selected, baseline)
    
    # Step 5: Design A/B tests (calculate sample sizes)
    plans = [self._designer.design_test(p, baseline) for p in plans]
    
    # Step 6: Allocate budget
    plans = self._allocator.allocate(plans, total_budget=2000, mode=BudgetMode.FIXED)
    
    # Step 7: Track (start all experiments)
    for plan in plans:
        self._tracker.start(plan)
    
    # Step 8: Analyze results (uses mock data in v1.0)
    results = self._analyze_with_mock_data(plans, baseline)
    
    # Step 9: Generate feedback signals
    signals = self._feedback.generate_feedback(results, selected)
    
    # Step 10: Apply feedback to E9.7
    self._feedback.apply_feedback_to_e97(signals)
    
    # Step 11: Export all outputs
    paths = self._exporter.export_all(plans, results, signals)
    
    return {"status": "success", "summary": {...}, "export_paths": paths}
```

# 6. Release Gate

## AC1: Experiment Generation
- **Requirement**: >=20 experiments from top_mutations.json
- **Test**: `len(select(top_mutations, top_n=20)) >= 20`

## AC2: Experiment Completeness
- **Requirement**: Every experiment has hypothesis, control, variant, metrics, budget, duration
- **Test**: `all(p.hypothesis and p.control and p.variant and p.metrics and p.budget > 0 and p.duration_days > 0 for p in plans)`

## AC3: Budget Strategies
- **Requirement**: Fixed, Dynamic, Bandit all supported
- **Test**: Each mode produces valid budget allocations

## AC4: Winner Analysis
- **Requirement**: Output winner, lift, confidence, decision
- **Test**: `all(r.decision in ["WINNER", "FAILED", "INCONCLUSIVE"] and r.lift is not None for r in results)`

## AC5: Feedback Signal
- **Requirement**: Feedback signals generated for E9.7
- **Test**: `len(signals) > 0 and all(s.dna_weight_update or s.mutation_strategy_update for s in signals)`

## AC6: Architecture Constraints
- **Requirement**: No modification to E9.5, E9.6, E9.8
- **Test**: Grep audit — no imports from `experiment_intelligence` in E9.5/E9.6/E9.8
