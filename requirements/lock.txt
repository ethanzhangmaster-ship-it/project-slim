#   1. Edit requirements/base.txt or requirements/dev.txt (keep `>=` ranges).
#   2. Re-resolve in a clean venv:
#        python -m venv .venv && .venv/Scripts/python -m pip install -r requirements/base.txt -r requirements/dev.txt
#        .venv/Scripts/python -m pip freeze > requirements/lock.txt
#   3. Re-run the full test suite + security scan before committing.
#
# NOTE: CI installs requirements/base.txt + requirements/dev.txt (ranges) for
#       the smoke test, then this lock is the source of truth for reproducible
#       production builds. To lock production builds, install -r requirements/lock.txt.
